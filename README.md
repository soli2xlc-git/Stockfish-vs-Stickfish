# Stockfish vs. Stockfish

Eine browserbasierte Schachsimulation, in der zwei Stockfish-Engines gegeneinander spielen.

Die Website ermöglicht es, einer laufenden Schachpartie zuzusehen und verschiedene Einstellungen der beiden Engines anzupassen.

## Features

- Zwei Stockfish-Engines spielen automatisch gegeneinander
- Anzeige des aktuellen Schachbretts
- Anzeige des Spielstatus und des letzten Zuges
- Zugliste zur Übersicht der bisherigen Partie
- Anpassbare Spielstärke für Weiß und Schwarz
- Einstellbare Bedenkzeit pro Zug
- Anpassbares Tempo zwischen den Zügen
- Optionale Abwechslung bei der Zugauswahl
- Anzeige der aktuellen Stellungsbewertung
- Möglichkeit, die Partie zu pausieren oder eine neue Partie zu starten
- Option zum automatischen Start einer neuen Partie nach Spielende

## Verwendung

Die Website läuft direkt im Browser und benötigt keine Installation.

1. Öffne die Website.
2. Zwei Stockfish-Engines starten automatisch eine Partie.
3. Passe bei Bedarf die Spielstärke, Bedenkzeit oder das Tempo an.
4. Beobachte die Partie und die einzelnen Züge.
5. Starte jederzeit eine neue Partie oder pausiere die aktuelle Simulation.

## Einstellungen

### Spielstärke

Die Stärke von Weiß und Schwarz kann unabhängig voneinander angepasst werden. Dadurch können unterschiedlich starke Engines gegeneinander antreten.

Eine Stärke von `0` entspricht einer sehr schwachen Spielweise, während `20` die volle eingestellte Stärke verwendet.

### Bedenkzeit

Die Bedenkzeit bestimmt, wie lange eine Engine maximal über einen Zug nachdenken kann.

### Tempo

Das Tempo bestimmt die Pause zwischen den einzelnen Zügen und beeinflusst, wie schnell die Partie auf dem Bildschirm abläuft.

### Abwechslung

Mit der Abwechslungs-Einstellung kann die Wahrscheinlichkeit angepasst werden, dass nicht immer der bestbewertete Zug ausgewählt wird. Dadurch können die Partien abwechslungsreicher verlaufen.
